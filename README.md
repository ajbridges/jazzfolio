# Jazzfolio

Bay Area jazz in one place: what's happening at the venues, a calendar of shows, and the rooms we watch in San Francisco, Oakland, Berkeley and Stanford.

This repo is a design-led exploration of that product. Three directions ship side by side (`/v1`, `/v2`, `/v3`) on top of the [ajbridges/design-system](https://github.com/ajbridges/design-system) starter (`v0.1.0`).

```bash
npm install
npm run dev
```

`npm run check:ds` fails if UI hardcodes colors outside the design-system tokens.
