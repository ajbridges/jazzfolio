# Jazzfolio

Bay Area jazz in one place: what's happening at the venues, a calendar of shows, and the rooms we watch in San Francisco, Oakland, Berkeley and Stanford.

This repo is a design-led exploration of that product, on the [ajbridges/design-system](https://github.com/ajbridges/design-system) starter (`v0.1.0`). Product notes are in `PRODUCT.md`. Venues, references, and the typed mock catalog live in `data/`, `docs/references/`, and `src/lib/data/`. Visual directions are not in this branch yet.

```bash
npm install
npm run dev
```

`npm run check:ds` fails if UI hardcodes colors outside the design-system tokens.
